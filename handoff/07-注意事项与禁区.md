# 07 · 注意事项与禁区

这份文档列出接手后最容易踩的坑和绝对不能做的事。

## 绝对不能做

1. **秘密不进 Git、不进对话**：服务器私钥、GitHub 部署密钥私钥、生产 `.env`（数据库密码、JWT_SECRET）、任何密码与令牌、P0 包及其口令、数据库导出。需要确认存在时只看文件名、大小、指纹。
2. **教材 PDF 永不上传**：四本教材只作大哥个人复习备份，不进仓库、不进任何公开位置。
3. **仓库保持私有**：不改公开；不强推；不改写 `master` 历史；不动 tag `v20`。
4. **备案前不推广**：ICP 备案通过前，网站只用 IP 自测，不发宣传片、不对外分享链接。
5. **网站内容红线**：不写所用技术（Three.js、高斯泼溅等）；不写辅导书或教材出处（官方大纲、真题可以）。构建里的 `check:sources` 敏感词扫描必须 0 命中。
6. **不要再提 UNED。**

## 先问大哥再做

- 执行 h2、改防火墙或安全组、轮换 JWT_SECRET、删除服务器上的旧公钥。
- 任何会让在线用户掉线或数据变化的操作（数据库迁移、恢复备份）。
- 花钱的事（买域名、语音接口付费、服务器升级）。
- 第三方合作项目的报价和是否承接。

## 已被否掉的方向（不要再提议）

- 闯关模式、排行榜、错题本、学习进度、自测题。
- 高斯泼溅整机（已改真实网格模型；原因是放大发糊、拆解卡）。
- 深色霓虹、紫色渐变、毛玻璃、emoji 图标等“AI 味”设计；花哨装饰。
- 2048、贪吃蛇等老式经典小游戏；糖果风。
- 禁右键/F12、debugger 陷阱这类“防扒”（误伤正常用户，对懂行的人无效）。

## 常见坑

- **主力视口**：横屏平板约 1210×680（扣掉浏览器栏），手机竖屏；每次改界面都在这两种视口截图核对，再看电脑端。
- **国内访问**：所有字体、脚本、模型本地打包；不引用国外 CDN。服务器构建用国内镜像（GOPROXY=goproxy.cn 等，已写进部署脚本）。
- **Caddy**：自定义编译约 20 分钟；改 Caddyfile 后先校验再上线（v20 曾因正则里的空格导致校验失败）；容器以 uid 10001 运行、去掉全部系统权限，Caddy 二进制不能带文件能力（v20 曾因此启动失败、中断约 2～3 分钟）。
- **限流**：大资源按 IP 限流，阈值照顾宿舍和学校共用出口 IP；改动后要用正常浏览器走一遍全站，确认不出 429。
- **下载工具拦截**：wget、curl、无头浏览器等默认身份访问资源返回 403 是预期行为；你自己用无头浏览器做线上截图时要换成正常浏览器身份，否则会被拦。
- **服务器 SSH**：fail2ban 5 次失败封 1 小时；多次试错会把沙盒出口 IP 封掉。连不上时先停下检查密钥和指纹，不要反复重试。
- **时间**：大哥在北京时间；沙盒和浏览器的时钟可能不是，汇报时间一律换算成北京时间。
- **单条命令时长**：大操作（构建、上传、克隆）拆成小步，后台执行并轮询日志。

## 汇报习惯

- 每块工作结束给一份短报告：做了什么、上线版本号、关键数字、前后对比截图、遗留问题、需要大哥决定的事（附默认值）。
- 数字现场核对（提交号、文件数、大小、字数），查不到写“未核实”，不凭印象。
