                  存储与地址映射

                  • 组成Cache映射↔操作系统页式存储/TLB

                    都是“地址划分 + 查表”，块↔页、Cache行↔页框

                  • 组成虚拟存储器↔操作系统虚拟内存

                    同一机制的硬件视角与 OS 视角

                  • 操作系统页式存储/TLB↔操作系统多级页表

                    页表太大就再分页

                  • 数据结构散列表↔组成Cache映射

                    直接映射 = 取模散列，组相联 = 散列 + 桶

                  • 操作系统文件索引分配↔操作系统多级页表

                    都是“索引的索引”，计算方法同构

                  中断、I/O 与磁盘

                  • 组成中断系统↔操作系统中断异常与系统调用

                    硬件负责响应，OS 负责处理程序

                  • 组成DMA↔操作系统I/O控制方式

                    程序查询→中断→DMA→通道，CPU 介入越来越少

                  • 数据结构栈↔组成函数调用与现场保存

                    调用、返回、中断现场都压栈

                  • 操作系统磁盘调度↔数据结构外部排序

                    外排序瓶颈是 I/O 次数，磁盘访问时间决定代价

                  队列、缓冲与同步

                  • 数据结构队列↔操作系统进程调度/就绪队列

                    就绪队列本身就是队列，FCFS 即出队顺序

                  • 数据结构队列↔网络路由器输出队列

                    分组排队产生排队时延

                  • 数据结构循环队列↔操作系统生产者-消费者

                    有界缓冲区就是循环队列，满/空对应 empty/full 信号量

                  • 操作系统生产者-消费者↔操作系统缓冲区

                    缓冲区是同步问题的载体

                  • 组成指令流水线↔操作系统进程同步

                    都是“相关/依赖导致等待”，气泡≈阻塞

                  窗口与路由算法

                  • 数据结构循环队列↔网络滑动窗口GBN/SR

                    序号取模循环使用，窗口即队列的一段

                  • 网络滑动窗口GBN/SR↔网络TCP流量控制

                    链路层窗口思想在传输层再现，窗口 = min(rwnd, cwnd)

                  • 数据结构图·Dijkstra↔网络OSPF

                    链路状态协议用 Dijkstra 算最短路径树

                  • 数据结构Bellman-Ford思想↔网络RIP

                    距离向量 = 邻居距离 + 1 的迭代

                  图、树与散列

                  • 操作系统死锁·资源分配图↔数据结构拓扑排序/环检测

                    资源分配图化简等价于找环

                  • 数据结构B+树↔操作系统文件索引分配

                    多级索引就是一棵多叉索引树

                  • 数据结构散列表↔网络交换机MAC表

                    按 key 直接定位转发端口

                  二进制位运算

                  • 组成补码与二进制运算↔网络CRC校验

                    CRC 用模 2 除法（异或）

                  • 组成补码与二进制运算↔网络子网掩码

                    地址与掩码按位与得网络号
