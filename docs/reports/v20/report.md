## 三、防扒做到了什么程度

先说清楚：**浏览器里运行的代码不可能绝对防扒**，能做的是大幅提高拿走和复用的成本。

现在别人打开开发者工具会看到：
- 所有脚本、样式都是压缩过的，没有任何开发注释；文件名是随机哈希（如 `eR4Fbx-m.js`），看不出是哪个模块。
- 旧版实验室模块（/lab 的核心）在构建时统一压缩、混淆、哈希命名；核心分块变量名没有含义，中文文字编码存放，直接搜索搜不到。
- 线上不提供 source map。
- 对比图：`/workspace/work/v20/shots/obfuscation-before-after.png`

整站下载与盗链：
- wget、HTTrack、curl、Python 脚本、无头浏览器等工具的默认身份访问脚本和模型资源 → **403**；页面本身照常打开。
- 其他网站直接引用我们的模型和脚本 → **403**；直接打开、从收藏夹或微信里打开（没有来源）→ 正常。
- 大资源按 IP 限流，阈值是一个人完整浏览全站请求数的 5 倍以上，照顾宿舍、学校共用出口 IP；超出时显示中文提示“访问太频繁了，请稍等一分钟再试”。
- 构建时会生成版权指纹清单，只存在本地，不进仓库、不上服务器。

没有做的：禁用右键 / F12、debugger 陷阱。原因是对懂行的人无效，却会影响正常同学、读屏和翻译工具。

## 五、需要你自己决定或操作的事（按优先级）

1. **新账号私钥登录确认 → 执行 h2（关闭 SSH 密码登录、root 只允许密钥）。** 现在服务器还接受密码登录，是目前最大的安全缺口。在新 Hark 账号用私钥登录成功后告诉我，我再执行。
2. **买域名并完成 ICP 备案。** 没有域名就没法用正式 HTTPS 证书，登录信息在网上是明文传输。备案完成后，在 .env 里设置 DOMAIN 即可自动申请证书、开启 HSTS、Cookie 加 Secure、HTTP 自动跳转。备案前不要对外推广。
3. **腾讯云控制台安全组同步只放行 22、80、443**，和服务器防火墙形成双层保护。
4. **是否修改 SSH 端口、是否禁用 root 登录**：有锁死风险，这次没做，只是建议。等 h2 稳定后再考虑。
5. 真机体验：请在你的手机和平板上点开化身数据和几个实验看看流畅度，有卡顿告诉我。
