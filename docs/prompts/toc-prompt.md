# 实验室侧边目录：下拉折叠式改版 · 执行 Prompt

## 一、站长原话与截图

> 侧边栏这里增加下拉式选项 UI。

截图拍的是平板横屏（约 1210 CSS 像素宽）下的 `/lab#prop`。左侧目录从上到下依次是：概览、数据结构、组成原理、操作系统、计算机网络、动画实验（下面平铺 39 个实验）、过程图解（平铺 36 个图解）、性质与公式（平铺 56 条性质）、3D 主板、知识图谱。截图里能看到“NAT 地址转换”“以太网交换机自学习与转发”“ping 与 traceroute”“电子邮件的发送与读取”这些过程图解条目，紧接着“性质与公式”标题下又是一长串“二叉树叶子结点数：n₀ = n₂ + 1”“二叉树的结点数上界……”。

## 二、深度剖析：站长真正要什么

### 1. 问题在哪里

目录最初只有十来个区块链接，那时一眼就能看完。后来动画实验从 3 个增加到 39 个，过程图解增加到 36 个，又加入了 56 条性质，每一项都平铺挂在目录里，目录总共超过 140 行。结果是：

- **找不到区块**：想从“性质与公式”跳回“四门课”或“3D 主板”，要在目录里滚动好几屏，目录本来是用来“快速定位”的，现在反而要“找目录”。
- **层级看不出来**：区块标题和子条目只靠缩进和一条竖线区分，字号差别小，扫一眼分不清哪些是大区块、哪些是条目。
- **看不出当前位置**：页面滚到第 40 条性质时，目录高亮只停留在“性质与公式”这个大标题上，子条目没有高亮，目录也不会自动滚到可见位置。
- **长标题折行**：“二叉树的结点数上界：2^(i−1) 与 2^h − 1”这类公式标题折成两行，让列表更长更乱。
- **四门课没有展开项**：而四门课恰恰是最常用的入口，章节却不能从目录直接跳到。

### 2. 站长说的“下拉式选项”

“下拉式”在这里指的是**可折叠分组**，而不是浏览器原生的 select 下拉框：每个大区块是一行标题，右侧有一个箭头和数量，点一下向下展开它的子条目，再点一下收起。这样平时目录只有十来行，干净；需要时展开某一组，精准跳转。这和 VS Code 的文件树、Notion 的侧栏、各类文档站点的侧边导航是同一种交互，站长和考研用户都很熟悉。

### 3. 设计目标

1. 收起状态下目录一屏放得下，一眼看清网站结构。
2. 每一组可单独展开、收起，展开时有平滑动画，箭头旋转指示状态。
3. 子条目多的组再按课程分二级组，例如“动画实验 → 数据结构 15 / 组成原理 8 / 操作系统 9 / 计算机网络 7”，二级组同样可折叠。
4. 当前所在的组自动展开，当前条目高亮，并自动滚动到目录可见区域内。
5. 记住用户手动展开、收起的状态，刷新页面后保持。
6. 手机和平板竖屏上，目录是从底部弹出的面板，同样采用折叠分组；平板横屏和电脑上是左侧固定侧栏。
7. 键盘和读屏软件可用。
8. 不改变网站现有配色和字体风格（UI 视觉改版站长说过之后再做），只改结构和交互。

## 四、交互细节

### 1. 展开与收起
- 组标题整行是一个按钮，左侧是标题文字，右侧是数量徽标和一个向右的箭头；展开时箭头旋转 90 度朝下。
- 点击组标题：如果这个组有对应区块（如“动画实验”），**箭头区域只负责展开收起，标题文字区域负责跳转到区块并同时展开**，避免用户想展开却被页面带走。实现方式：标题行内放两个可点元素——左侧链接、右侧展开按钮；在手机上两者都至少 44 像素高。
- 展开动画使用 grid-template-rows 从 0fr 到 1fr 或测量高度的方式，时长 180 ~ 220 毫秒；系统开启“减少动态效果”时无动画。
- 同一时间允许多个组展开（不是手风琴强制只开一个），但提供目录顶部的“全部收起”小按钮。

### 2. 默认状态
- 第一次访问时，所有组收起，只有当前所在区块的组展开。
- 用户手动展开、收起的状态保存在 localStorage（键名如 `x408.toc.open`），下次访问恢复；保存失败（隐私模式）时静默忽略。
- 从带锚点的链接进入（如 `#prop-ds-leaf`、`#lab-kmp`）时，自动展开对应顶层组和二级组，并高亮该条目。

### 3. 当前位置联动
- 滚动时，现有的区块侦测（scroll spy）继续高亮顶层组标题；同时：
  - 当前区块所在的组如果是收起的，自动展开（但不收起用户自己展开的其他组）。
  - 当用户在动画实验、过程图解、性质与公式中切换到某一项时（通过 `X_OPEN_LAB`、`X_OPEN_PROC`、`X_OPEN_PROP` 或点击页面上的标签），目录对应条目设置 `aria-current="true"` 高亮，并在侧栏内滚动到可见位置（scrollIntoView，block: nearest，仅滚动目录容器，不能让整页跳动）。
  - 四门课区块中切换章节时，章节条目同样高亮。
- 高亮样式：左侧 3 像素主色竖条 + 浅主色背景 + 中等字重。

### 4. 目录内筛选
- 目录顶部（“全部收起”旁边）放一个小搜索框“筛选目录”，输入后只显示标题匹配的条目，匹配的组自动展开，不匹配的组隐藏；清空后恢复原来的展开状态。这对 131 个条目非常有用，例如输入“TCP”立刻看到 TCP 相关的实验、图解和性质。
- 中文与英文、大小写不敏感；公式中的下标字符（n₀）与普通字符（n0）视为相同。

### 5. 长标题
- 条目单行显示，超出部分省略号，悬停或长按时通过 title 属性显示全称；性质条目的公式标题较长，可在目录里使用更短的“目录名”（例如“叶子结点数 n₀ = n₂ + 1”），数据中没有短名时退回完整标题。

### 6. 手机与平板竖屏
- 宽度小于 1024 像素时，侧栏隐藏，工具栏中的“目录”按钮打开底部面板（已有实现，保留）。面板内使用同样的折叠分组结构，高度不超过视口高度的 80%，内部独立滚动，顶部有拖动条和“全部收起”、筛选框。
- 点击条目后关闭面板并跳转；点击组标题的展开按钮时不关闭面板。
- 面板打开时锁定背景滚动，关闭后恢复。

### 7. 平板横屏与电脑
- 左侧固定侧栏（sticky），高度为视口高度减去顶栏，内部独立滚动；侧栏宽度 240 ~ 280 像素，大屏随容器略放宽。
- 侧栏滚动到底部或顶部时不带动整页滚动（overscroll-behavior: contain）。

## 五、可访问性

- 组标题的展开按钮使用 `<button aria-expanded="true|false" aria-controls="子列表 id">`，按钮内文字“展开动画实验”“收起动画实验”供读屏使用（视觉上隐藏）。
- 子列表使用 `<ol role="list">` 或语义化的嵌套列表，收起时设置 hidden 或 inert，确保 Tab 键不会进入收起的内容。
- 键盘：Tab 在可点元素之间移动；在组标题按钮上按 Enter 或空格切换展开；可选支持右方向键展开、左方向键收起。
- 焦点框清晰可见（2 像素主色描边）。
- 数量徽标对读屏读作“39 项”。

## 六、实现方案

1. **结构**：修改 `apps/web/public/legacy/body.html` 中 `#x-toc` 的静态结构：顶层每一项改为“组”结构（标题行 + 子列表），保留已有的 id（`x-toc-labs`、`x-toc-procs`、`x-toc-props`）以免破坏现有填充逻辑与测试，或在 JS 中同步修改。
2. **逻辑**：在 `js/09-tool.js` 中把 `fillToc`、`fillProcToc`、`fillPropToc` 改为按课程生成二级组；新增四门课章节填充；新增展开状态管理（读写 localStorage、锚点自动展开、scroll spy 联动、当前条目高亮与滚动）、目录筛选、“全部收起”。如果 09-tool.js 过长，可新建 `js/28-toc.js` 并加入 manifest.json，保持加载顺序（在实验、图解、性质模块之后）。
3. **联动钩子**：在实验、图解、性质切换的入口（X_OPEN_LAB、X_OPEN_PROC、X_OPEN_PROP 以及各自标签点击）派发一个自定义事件，如 `document.dispatchEvent(new CustomEvent("x:active", { detail: { kind: "lab", id } }))`，目录监听该事件更新高亮。这比在各模块里直接操作目录更松耦合。
4. **样式**：新建 `css/legacy-16.css`（加入 manifest），定义组标题、箭头、徽标、二级组缩进、高亮、展开动画、筛选框、手机面板内的样式；复用现有颜色变量，课程色点沿用现有颜色。
5. **兼容**：保留旧的 `.x-toc > ol > li > a` 链接 href 不变，保证外部深链接和现有 scroll spy 测试继续通过；必要时更新测试选择器。

## 七、验收标准

1. 收起状态下，目录在 1366 × 768 的笔记本上不需要滚动即可看到全部顶层组。
2. 三个大组按课程二级分组，数量正确（实验 39、图解 36、性质 56，二级组数量之和等于总数）。
3. 打开 `/lab#prop-ds-leaf`：性质与公式组和“数据结构”二级组自动展开，该条目高亮且在侧栏可见范围内。
4. 在页面上切换实验、图解、性质、章节，目录高亮实时跟随。
5. 展开状态刷新后保持；隐私模式下不报错。
6. 筛选框输入“TCP”只显示相关条目；清空后恢复。
7. 键盘完整可操作，读屏能读出展开状态和数量。
8. 在 320、393、852 × 393、820 × 1180、1210 × 800（截图设备）、1366 × 1024、1920、2560 视口下：无横向溢出，无 JS 报错，手机面板与桌面侧栏均正常。
9. 全部单元测试、类型检查、lint、构建通过；为展开状态管理、筛选、锚点展开新增单元测试。
10. 部署后线上 `/lab` 返回 200，并用截图人工确认平板横屏下的效果与截图问题对比。

## 八、风险与注意事项

- 目录子项是在实验、图解、性质模块渲染后才填充的（监听 legacy:ready），新逻辑也要在此之后运行，并对重复调用做幂等处理。
- 多设备适配这一轮刚改过 `legacy-15.css` 中目录的断点与触控尺寸，新样式要建立在它之上，不要互相覆盖；断点沿用 1024（侧栏与面板的分界）。
- 自动滚动目录时只能滚动目录容器本身，绝不能触发整页滚动，否则会和 scroll spy 互相打架造成抖动。
- 不改变颜色与字体，留给之后的 UI 改版。

## 九、典型使用场景（用来检验设计是否顺手）

1. **考前查公式**：同学在平板上打开实验室，想看“香农定理”。他点开目录里的“性质与公式”，再点“计算机网络”，十四条性质出现，第二条就是香农定理，点一下页面跳到卡片。整个过程两次点击、不需要滚动目录。
2. **按章复习**：同学在电脑上复习操作系统第三章“内存管理”。点开目录里的“操作系统”，五个章节出现，点“内存管理”，页面滚到操作系统区块并切换到这一章。之后他想看页面置换的动画，在筛选框输入“置换”，目录里同时出现“页面置换”实验和“页面置换 Belady 异常”性质，点实验即可。
3. **从分享链接进入**：同学在群里收到 `/lab#lab-kmp` 链接，手机打开后直接看到 KMP 实验。他点“目录”，底部面板弹出，“动画实验 → 数据结构”已经自动展开，KMP 高亮，他能立刻知道这个实验在整个网站中的位置，并顺手点开相邻的“哈夫曼树”。
4. **长时间学习**：同学习惯把“动画实验”和“性质与公式”两组一直展开着，第二天打开网站，目录仍然保持这两组展开，其余收起。
5. **边看边对照**：同学在大屏电脑上一边看 Floyd 动画，一边从目录展开“过程图解 → 数据结构”，点开相关图解，再回到实验时目录高亮跟着切换，始终知道自己在哪里。

## 十、视觉与尺寸规格（沿用现有颜色和字体）

- 顶层组标题：字号 14 ~ 15 像素，字重 600，行高 40 像素（触控设备 44），左侧可带课程色点（四门课组）。
- 二级组标题：字号 13 像素，字重 500，颜色比正文略浅，左侧缩进 12 像素，行高 36 像素（触控 44）。
- 条目：字号 13 像素，左侧缩进 24 像素，行高 32 像素（触控 44），单行省略。
- 数量徽标：圆角胶囊，字号 12 像素，浅灰背景，位于标题右侧、箭头左侧。
- 箭头：12 像素的细线 V 形图标，收起时朝右，展开时朝下，旋转过渡 180 毫秒。
- 组与组之间 4 像素间距；展开的组下方有一条极浅的分隔线。
- 筛选框高度 32 像素（触控 40），圆角与现有搜索框一致，占侧栏全宽；“全部收起”为文字按钮，放在筛选框右侧或侧栏标题行右侧。
- 高亮条目：左侧 3 像素主色竖条、浅主色背景、字重 500；悬停（仅鼠标设备）浅灰背景。

## 十一、状态模型

为便于测试，把目录状态抽成一个纯函数模块：

- `openSet`：已展开的组 id 集合，例如 `["lab", "lab:ds", "prop", "prop:cn"]`。
- `active`：当前条目，例如 `{ kind: "prop", id: "cn-shannon" }`。
- `filter`：筛选关键词。
- 纯函数：`toggle(openSet, id)`、`ensureOpenFor(openSet, active)`（返回包含 active 所属顶层组和二级组的新集合）、`matchItems(items, filter)`（返回匹配条目及需要展开的组）、`serialize / parse`（读写 localStorage，解析失败返回空集合）。
- DOM 层只负责根据状态渲染 aria-expanded、hidden 与高亮。这样单元测试可以覆盖展开逻辑而不依赖浏览器。

## 十二、边界情况

- 某门课在某一大组中没有条目时，不渲染这个二级组。
- 筛选无结果时，目录显示“没有匹配的条目”，并提供“清空筛选”。
- 窗口在 1024 像素上下来回缩放时，侧栏与底部面板切换，展开状态共享，不丢失。
- 页面区块被隐藏（hidden）时，对应目录组也隐藏。
- localStorage 中存了已不存在的组 id（以后删了某个实验）时，忽略即可。
- 实验或性质数量以后增加时，目录自动适配，无需修改目录代码。

## 十四、为什么不用原生下拉框

站长说“下拉式选项”，最直接的理解也可能是一个 select 下拉框，例如在侧栏顶部放“选择区块”的下拉菜单。之所以选择可折叠分组，是因为：第一，原生下拉框一次只能看到一个选项，131 个条目放进去要在弹出列表里长时间滚动，在手机上还会变成系统的滚轮选择器，体验更差；第二，下拉框选中后就收起，看不到当前位置在整体结构中的位置，失去了目录“地图”的作用；第三，折叠分组同时具备“下拉展开”的视觉动作和“常驻可见”的导航作用，既满足站长想要的“下拉”感，又保留目录的全局视野。

不过，为了照顾站长可能想要的“下拉菜单”形式，在侧栏顶部的筛选框左侧可以额外放一个紧凑的“跳到区块”菜单按钮：点开后弹出一个小菜单，列出十个顶层区块，点击即跳转并展开对应组。这个菜单使用自定义的弹出层而不是原生 select，样式与目录统一，支持键盘上下选择和 Esc 关闭。它是快速跳转的补充，不替代折叠分组。

## 十五、与其他正在进行的工作的关系

- **多设备适配**：刚完成的多设备适配改动了实验室的断点、触控尺寸和底部目录面板，这次改版直接建立在它之上，断点继续以 1024 为侧栏与面板的分界。
- **去除辅导书痕迹**：同时进行的另一项工作会改写目录里的部分条目名称（例如个别实验和性质的标题），目录是从页面数据自动生成的，名称改动会自动同步，不需要在目录里单独处理。
- **之后的 UI 改版**：这次只用现有颜色变量，所有尺寸写成 CSS 变量（例如 `--x-toc-row`、`--x-toc-indent`），方便以后统一换风格时一次调整。

## 十六、测试清单
