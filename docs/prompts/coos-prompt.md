## 一、站长原话与现状

站长原话：

> 组成原理和操作系统也要有动画实验和图解。

`/lab` 实验室目前的情况：

- 组成原理：动画实验只有 2 个（Cache 地址映射、指令流水线）；过程图解 9 个（基本逻辑门、加法器、译码器、指令周期数据流、微程序控制器、带 TLB 的虚存访问、TLB + Cache 地址转换、单重 / 多重中断、DMA）。
- 操作系统：动画实验 3 个（CPU 调度甘特图、页面置换、银行家算法）；过程图解 7 个（引导过程、系统调用、进程状态转换、进程切换、二级页表、混合索引、设备分配）。

过程图解已经覆盖了“流程图类”考点，但“给一组数据、按算法一步步算”的动画实验明显偏少。组成原理第二章（数据的表示和运算）是整门课计算量最大的一章，浮点数、补码乘法、校验码几乎每年都有选择题，常进综合题；第四章的寻址方式是综合题必问的“有效地址怎么算”。操作系统里磁盘调度、动态分区分配、PV 同步是综合题的老三样，同时也是选择题的高频点。这些全都缺少可以自己改数据反复练的实验。

所以这一次的重点是：**补齐组成原理、操作系统中“按算法逐步计算”的动画实验，并在过程图解里再补上几张常考流程。**

## 二、深度剖析：站长真正要什么

1. **“动画实验”与“过程图解”是两种不同的学习方式。** 图解是“看懂一个固定流程”；实验是“自己出题、自己算、对答案”。站长说“也要有动画实验和图解”，意思是组成原理和操作系统也要有计网那样“可以随便改数字反复练”的东西，而不只是看流程。所以新增的每个实验都必须有输入，任何合法输入都能算出正确结果，并逐步展示中间过程。
2. **计算过程必须像草稿纸一样完整。** 浮点数转换要一步一步写出：十进制 → 二进制 → 规格化 → 阶码加偏置 → 拼出 32 位 → 十六进制；Booth 乘法要一行一行写出部分积、乘数、附加位和每一步的操作（+[X]补、+[−X]补、右移）。学生考试时要写过程，所以图解里的格式就是答题格式。
3. **综合题会问统计量。** 磁盘调度要算总寻道长度和平均寻道长度；动态分区分配要看每次分配后的空闲分区链和外部碎片；寻址方式要算有效地址和访存次数；PV 同步要看信号量值、谁被阻塞、谁被唤醒。这些统计量必须随步骤实时显示。
4. **算法对比要一键切换。** 磁盘调度的 FCFS / SSTF / SCAN / C-SCAN / LOOK / C-LOOK，动态分区的首次 / 邻近 / 最佳 / 最坏适应，同一组数据切换算法立刻看到差别，这是选择题最常考的比较。
5. **和已有内容不重复。** 页面置换、银行家、调度、Cache 映射、流水线已经有，不再重做；新实验与它们形成互补。
6. **手机好用。** 输入框数字键盘、按钮足够大、结果表格可横向滑动，不溢出页面。

## 三、范围

### A. 组成原理动画实验

1. **IEEE 754 单精度浮点数。** 两个方向：十进制 → IEEE 754（输入如 −0.75、12.375、0.1），逐步展示符号位、整数和小数部分转二进制（小数部分乘 2 取整，0.1 这样的无限循环要显示截断）、规格化为 1.xxx × 2^E、阶码 = E + 127 的二进制、尾数去掉隐藏位后的 23 位，拼成 32 位并按 4 位一组转十六进制；IEEE 754 → 十进制（输入 8 位十六进制，如 C1480000），反向拆字段计算。特殊值：阶码全 0（非规格化数、±0）、全 1（±∞、NaN）要正确识别。显示表示范围要点：最大正规格化数、最小正规格化数。
2. **Booth 补码一位乘法。** 输入两个 n 位（默认 4 位，可选 4 / 6 / 8）有符号整数 X、Y，逐步展示：[X]补、[−X]补、初始部分积 0、乘数 [Y]补 和附加位 Y₋₁ = 0；每一步看 YₙYₙ₊₁（课本记作 Y_n Y_{n+1}）两位：00 / 11 只右移，01 加 [X]补后右移，10 加 [−X]补后右移；部分积用双符号位，算术右移；共做 n 次加法判断、n 次移位（最后一次不移位的教材写法要注明差异），得到 2n 位乘积并换算成十进制核对。表格每一行就是答题纸的一行。
3. **海明码（汉明码）。** 输入信息位（如 1010），计算需要的校验位数 k（满足 2^k ≥ n + k + 1），把校验位放在 1、2、4、8… 位置，逐个计算 P1、P2、P4…（各自负责哪些位，异或得出），拼成海明码；再输入一个“出错位置”或直接输入接收到的码字，计算校验和 S，指出出错位并纠正。可选偶校验 / 奇校验，默认偶校验。
4. **指令寻址方式与有效地址。** 给一台示意机器：PC、通用寄存器 R0–R3、基址寄存器 BR、变址寄存器 IX，以及一段主存。输入形式地址 A 和寻址方式（立即、直接、间接、寄存器、寄存器间接、基址、变址、相对），展示 EA 的计算、取操作数需要访存几次、操作数是多少；相对寻址要说明 PC 是“取指后已加指令长度”的值。

### B. 操作系统动画实验

1. **磁盘调度。** 输入请求序列（如 98, 183, 37, 122, 14, 124, 65, 67）、磁头初始位置（53）、磁道范围（0–199）、初始移动方向。算法：FCFS、SSTF、SCAN（到端点再返回）、C-SCAN、LOOK、C-LOOK。画面：横轴磁道号、纵轴时间，折线逐段画出磁头轨迹；表格列出每次访问的磁道和移动距离；统计总寻道长度、平均寻道长度。还要说明 SSTF 可能“饥饿”，SCAN 对两端不公平，C-SCAN 更均匀。
2. **动态分区分配。** 内存 640KB（OS 占低端 40KB 可配置），输入一串作业请求与释放（如 “A 申请 130，B 申请 60，C 申请 100，B 释放，D 申请 200，C 释放，E 申请 140…”），算法：首次适应、邻近适应（循环首次）、最佳适应、最坏适应。画面：一条内存条，已分配块和空闲块按地址比例显示；空闲分区链表格（起址、大小），按算法要求的顺序排列（最佳适应按大小递增、最坏适应按大小递减）；释放时演示与上下相邻空闲区合并的四种情况；分配失败时提示外部碎片。
3. **生产者—消费者（PV 操作）。** 缓冲区 n 个（默认 3），信号量 mutex = 1、empty = n、full = 0；两个生产者、两个消费者的执行序列可选“随机一组”或手动点“生产者 P1 走一步”。每一步执行一条语句（P(empty)、P(mutex)、放入、V(mutex)、V(full)…），显示信号量的值、阻塞队列、缓冲区（循环队列，in / out 指针），被阻塞的进程变灰并排进信号量的队列，被 V 唤醒的进程回到就绪。附“把 P(mutex) 放到 P(empty) 前面会死锁”的演示模式。

### C. 补充过程图解

1. **Cache 读写流程（组成原理）。** 读：命中直接读；缺失则从主存调块（满则按替换算法选一行，若该行脏位为 1 先写回）。写：写命中时“全写法（写直达）同时写主存，常配写缓冲”与“写回法只写 Cache、置脏位”；写缺失时“写分配法（调块后写）”与“非写分配法（直接写主存）”。三个模式：读、写命中、写缺失。
2. **文件的打开与读取过程（操作系统）。** open：按路径逐级查目录（根目录 → 子目录），找到 FCB / 索引结点，把它读入内存的系统打开文件表，在进程打开文件表中建立表项，返回文件描述符；read：用文件描述符查进程打开文件表 → 系统打开文件表 → 索引结点 → 由文件读写指针算出逻辑块号 → 物理块号 → 读盘到缓冲区 → 复制到用户区；close：引用计数减 1。
3. **SPOOLing 假脱机（操作系统）。** 多个进程请求打印：输出进程把数据写入磁盘上的输出井，系统为每个请求建立打印请求表并排队，独占的打印机被改造成“共享”的虚拟设备，输出进程按队列依次把输出井中的数据送打印机。

## 六、验收标准

1. IEEE 754：−0.75 → BF400000；12.375 → 41460000；C1480000 → −12.5；0 → 00000000；7F800000 → +∞；0.1 → 3DCCCCCD（舍入到最近，显示截断与舍入说明）。

## 七、内容质量要求

- 浮点数：阶码偏置 127，尾数 23 位隐藏最高位 1；非规格化数阶码视为 −126、无隐藏位。
- Booth：部分积采用双符号位，加法后算术右移，最后一步只加不移（按唐朔飞教材写法），表格首行写初值。
- 海明码：校验位位置是 2 的幂；Pi 负责位置编号二进制中第 i 位为 1 的所有位；校验和 S 的值就是出错位置。
- 磁盘调度：SCAN 严格到达端点再返回；LOOK 只到最远请求；SSTF 距离相同时取当前移动方向上的那一个，并注明。
- 动态分区：邻近适应从上次分配结束的位置继续找；释放合并后空闲链要保持算法要求的顺序。
- PV：P 操作 S−1 后 < 0 则阻塞；V 操作 S+1 后 ≤ 0 则唤醒一个。信号量值为负时，其绝对值等于阻塞进程数。

## 八、逐步脚本（实现时每一步的文字依据）

### IEEE 754：−0.75 → 十六进制
第一步确定符号：负数，S = 1；第二步取绝对值 0.75，整数部分 0 转二进制为 0；第三步小数部分乘 2 取整：0.75 × 2 = 1.5 取 1，0.5 × 2 = 1.0 取 1，结束，得 0.11；第四步规格化：0.11 = 1.1 × 2^−1，指数 E = −1；第五步阶码 = E + 127 = 126 = 0111 1110；第六步尾数取小数点后的部分 1，补足 23 位：100 0000 0000 0000 0000 0000；第七步拼接 1 | 01111110 | 10000000000000000000000，按 4 位一组得 BF400000。0.1 的例子要展示小数部分 0.0001100110011… 无限循环，取够 24 位有效位后按“舍入到最近、恰好一半时取偶”得到 3DCCCCCD，并提示这就是浮点数 0.1 不能精确表示的原因。

### Booth：X = 5、Y = −3（4 位）
[X]补 = 0101，[−X]补 = 1011，[Y]补 = 1101，附加位 Y₋₁ = 0。初值：部分积 00 0000，乘数 1101 0。第一步看末两位 10 → 加 [−X]补，部分积 11 1011，然后连同乘数一起算术右移一位；第二步看末两位 01 → 加 [X]补；第三步 10 → 加 [−X]补；第四步 11 → 只右移；最后得到 8 位乘积 1111 0001 = −15。每一行写出：步骤、条件、操作、部分积、乘数、附加位，与教材答题格式一致。

### 海明码：信息位 1010
n = 4，试 k = 3：2^3 = 8 ≥ 4 + 3 + 1，满足；位置 1–7 中 1、2、4 放校验位，3、5、6、7 依次放 D1–D4 = 1、0、1、0；P1 负责位置 1、3、5、7：P1 = D1 ⊕ D2 ⊕ D4 = 1 ⊕ 0 ⊕ 0 = 1；P2 负责 2、3、6、7：P2 = D1 ⊕ D3 ⊕ D4 = 1 ⊕ 1 ⊕ 0 = 0；P4 负责 4、5、6、7：P4 = D2 ⊕ D3 ⊕ D4 = 0 ⊕ 1 ⊕ 0 = 1；海明码为 1 0 1 1 0 1 0。接收端若第 5 位翻转，重新计算 S4 S2 S1 = 1 0 1 = 5，指出第 5 位出错并取反纠正。另外说明：再加一位总校验位可以“纠一位、检两位”。

### 磁盘调度：SSTF
磁头在 53，未访问的请求中离 53 最近的是 65（距离 12），然后 67（2）、37（30）、14（23）、98（84）、122（24）、124（2）、183（59），总寻道长度 236，平均 236 / 8 = 29.5。每一步在折线图上画一段，并在表格里写出“当前位置、选中磁道、移动距离、累计距离”。SCAN 从 53 向大号方向依次访问 65、67、98、122、124、183，到达 199 端点后折返访问 37、14，总长 (199 − 53) + (199 − 14) = 331。

### 动态分区分配：首次适应
初始：OS 占 0–40K，空闲区 40K–640K（600K）。A 申请 130K：从低地址找第一个够大的空闲区，分配 40–170K，剩余空闲区 170–640K；B 申请 60K：分配 170–230K；C 申请 100K：分配 230–330K；B 释放：170–230K 变空闲，上下相邻都是已分配区，不合并；D 申请 200K：170–230K 只有 60K 不够，继续向后在 330–640K 中分配 330–530K；C 释放：230–330K 变空闲，上邻空闲区 170–230K，合并为 170–330K（160K）；E 申请 140K：首次适应找到 170–330K，分配 170–310K。切换到最佳适应时，空闲分区链按大小递增排序，每次选能满足的最小空闲区，同一序列会落到不同位置。

### 生产者—消费者
第一步 P1 执行 P(empty)：empty 3 → 2，不阻塞；第二步 P1 执行 P(mutex)：mutex 1 → 0，进入临界区；第三步 P1 把产品放入 buffer[in]，in = (in + 1) mod 3；第四步 V(mutex)：mutex 0 → 1；第五步 V(full)：full 0 → 1，若有消费者在 full 上阻塞则唤醒一个。当缓冲区已满时生产者执行 P(empty) 使 empty 变成 −1，生产者被放进 empty 的阻塞队列；之后某消费者取走产品并执行 V(empty)，empty 由 −1 变 0，唤醒该生产者。错误顺序模式：生产者先 P(mutex) 再 P(empty)，缓冲区满时生产者占着 mutex 阻塞在 empty 上，消费者又在 P(mutex) 上阻塞，二者互相等待，形成死锁。

### 指令寻址实验
示意机器：PC = 1000，R1 = 2000，BR = 3000，IX = 0100，主存 0200 号单元内容 2500、2500 号单元内容 7777……输入形式地址 A = 0200：立即寻址操作数就是 0200，不访存；直接寻址 EA = 0200，访存 1 次取得操作数 2500；间接寻址先访存取得 EA = 2500，再访存取得操作数 7777，共 2 次；寄存器寻址操作数在 R1，不访存；寄存器间接 EA = (R1) = 2000，访存 1 次；基址寻址 EA = (BR) + A = 3200；变址寻址 EA = (IX) + A = 0300；相对寻址 EA = (PC) + A，其中 PC 是取指后已自增的值。考点：基址寄存器由操作系统管理、面向系统，适合多道程序；变址寄存器由用户使用、面向用户，适合数组和循环；相对寻址便于程序浮动。

### Cache 读写图解
读命中：按地址找到 Cache 行，直接返回数据；读缺失：从主存读出整个块，若该组已满则按替换算法（LRU、FIFO、随机）选一行，若该行脏位为 1 先写回主存，再装入新块并返回数据。写命中、全写法：同时写 Cache 和主存，为减少等待增加写缓冲，Cache 行不需要脏位；写命中、写回法：只写 Cache 并置脏位，等这一行被替换时才写回主存。写缺失、写分配法：先把块调入 Cache 再写，通常与写回法搭配；写缺失、非写分配法：直接写主存，不调块，通常与全写法搭配。

### 文件打开与读取图解
open("/home/a.txt")：第一步从根目录的索引结点出发，读入根目录文件，查到 home 的索引结点号；第二步读入 home 目录文件，查到 a.txt 的索引结点号；第三步把 a.txt 的索引结点读入内存，在系统打开文件表中建立表项（若已有则打开计数加 1）；第四步在进程打开文件表中建立表项，指向系统打开文件表项，记录读写指针和访问权限；第五步返回文件描述符。read(fd, buf, n)：用 fd 找到进程打开文件表项，再找到系统打开文件表中的索引结点；根据读写指针计算逻辑块号，通过索引结点中的地址项得到物理块号；先查磁盘高速缓存，没有再读盘；把数据复制到用户缓冲区并移动读写指针。考点：open 之后读写文件不再需要查目录，所以打开文件能减少检索目录的次数。

### 磁盘调度补充与动态分区释放
C-SCAN 从 53 向大号方向访问到 183，继续到 199，立即回到 0（回程不访问任何请求），再访问 14、37；若计回程，总长 (199 − 53) + 199 + 37 = 382。动态分区释放合并的四种情况：只与上邻空闲区相邻，合并后起址取上邻起址；只与下邻相邻，起址取回收区起址；上下都相邻，三块合为一块，空闲区数量减一；都不相邻，新增一个空闲区并按算法要求的顺序插入链表。

### SPOOLing 与 Booth、海明码补充说明
SPOOLing 图解的步骤：进程 A、B、C 先后请求打印；输入进程 / 输出进程是系统中常驻的两个进程，模拟脱机输入输出的外围控制机；系统为每个请求在磁盘输出井中申请一块区域，把要打印的数据从用户进程的内存区送入输出缓冲区，再写入输出井；同时填写一张打印请求表挂到打印队列上；打印机空闲时，输出进程从队首取出一张请求表，把输出井中对应的数据经缓冲区送打印机；每个进程都以为自己独占了一台打印机，实际上是共享一台物理打印机。考点：SPOOLing 把独占设备改造成共享设备，提高了 I/O 速度，需要磁盘作为输入井和输出井，是以空间换时间的技术。Booth 算法补充：乘数的符号位也参与运算，所以补码乘法不需要单独处理符号；部分积采用双符号位是为了防止加法时溢出导致右移出错。海明码补充：校验位个数满足 2^k ≥ n + k + 1 是为了让 k 位校验和能表示“无错”和 n + k 个可能出错的位置。

### 磁盘调度、动态分区与 PV 的考点笔记要点
磁盘调度考点笔记写四条：一次磁盘访问时间 = 寻道时间 + 旋转延迟 + 传输时间，调度算法只能优化寻道时间；FCFS 公平但效率低；SSTF 平均寻道最短但可能饥饿，而且不保证总寻道长度最优；SCAN 又叫电梯算法，C-SCAN 消除了对两端磁道的不公平。动态分区考点笔记写四条：首次适应综合性能最好、开销小，低地址容易留下小碎片；邻近适应使碎片在整个内存中分布均匀，但大分区容易被用完；最佳适应会产生大量难以利用的小碎片；最坏适应很快耗尽大分区，不利于大作业。生产者—消费者考点笔记写三条：互斥信号量的 P 操作必须放在同步信号量的 P 操作之后，否则可能死锁；V 操作的顺序可以交换；实现互斥的 P、V 在同一进程中成对出现，实现同步的 P、V 在不同进程中成对出现。浮点数考点笔记：规格化尾数最高位为 1 所以可以隐藏；阶码用移码表示便于比较大小；单精度正数范围约 1.18 × 10^−38 到 3.4 × 10^38。

寻址方式考点笔记：立即寻址最快但操作数大小受形式地址位数限制；间接寻址扩大寻址范围但多访存；寄存器寻址不访存、速度快；相对寻址的位移量是补码，可正可负，用于转移指令。Cache 读写考点：写回法减少访存次数但要维护脏位，全写法保证一致性但写操作频繁访存。
