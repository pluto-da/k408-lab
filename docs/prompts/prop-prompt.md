## 三、内容范围（首批 56 条，每门课 14 条）

### 数据结构（14 条）

1. **二叉树叶子结点数**：n₀ = n₂ + 1。推导：n = n₀ + n₁ + n₂，分支数 B = n − 1 = n₁ + 2n₂。验证：随机生成或手动增删结点的二叉树，实时统计 n₀、n₁、n₂。
2. **二叉树的结点数上界**：第 i 层最多 2^(i−1) 个结点；高度为 h 最多 2^h − 1 个结点。验证：逐层填满满二叉树。
3. **完全二叉树的高度与编号**：n 个结点的完全二叉树高度 ⌈log₂(n+1)⌉（或 ⌊log₂n⌋ + 1）；编号 i 的结点父结点为 ⌊i/2⌋、左孩子 2i、右孩子 2i+1；叶子结点个数为 ⌈n/2⌉，最后一个非叶结点编号 ⌊n/2⌋；度为 1 的结点最多 1 个。验证：拖动 n，高亮任意结点的父、子编号。
4. **空指针数**：n 个结点的二叉链表有 2n 个指针域，其中 n − 1 个非空、n + 1 个为空，这正是线索二叉树能利用的线索数。链到线索化图解。
5. **卡特兰数**：n 个结点能构成的不同形态二叉树数、n 个元素的合法出栈序列数都是 C(2n, n)/(n+1)。验证：n ≤ 6 时枚举全部出栈序列并逐个判断合法性。
6. **树与森林**：树的结点数 = 所有结点的度之和 + 1；度为 m 的树第 i 层最多 m^(i−1) 个结点；n 个结点、k 棵树的森林有 n − k 条边。
7. **哈夫曼树**：n 个叶子的哈夫曼树共 2n − 1 个结点，没有度为 1 的结点；m 叉哈夫曼树需要补 (m−1) − (n−1) % (m−1) 个权值为 0 的虚结点（余数不为 0 时）。链到哈夫曼实验和最佳归并树图解。
8. **图的度与边**：无向图所有顶点度之和 = 2e；有向图入度之和 = 出度之和 = e。验证：随机图上实时求和。
9. **连通性与边数**：n 个顶点的无向完全图有 n(n−1)/2 条边、有向完全图 n(n−1) 条；连通图至少 n − 1 条边；非连通图最多 C(n−1, 2) 条边；保证一定连通至少需要 C(n−1, 2) + 1 条边；强连通有向图至少 n 条边。验证：拖动边数，看最“坏”的情况是否还能不连通。
10. **平衡二叉树最少结点数**：高度为 h 的 AVL 树最少结点数 N(h) = N(h−1) + N(h−2) + 1，N(0) = 0、N(1) = 1、N(2) = 2，所以 N(3) = 4、N(4) = 7、N(5) = 12、N(6) = 20。验证：画出每个高度的“最瘦”平衡二叉树。链到 AVL 实验。
11. **B 树的关键字数与高度**：m 阶 B 树根结点至少 1 个关键字，非根结点关键字数在 ⌈m/2⌉ − 1 到 m − 1 之间；含 n 个关键字、高度 h（不含失败结点层）的 B 树满足 log_m(n+1) ≤ h ≤ log_⌈m/2⌉((n+1)/2) + 1；失败结点数为 n + 1。链到 B 树实验。
12. **红黑树**：从根到叶的最长路径不超过最短路径的两倍；n 个内部结点的红黑树高度 h ≤ 2log₂(n+1)；黑高为 bh 的子树至少有 2^bh − 1 个内部结点。链到红黑树图解。
13. **折半查找与堆**：折半查找判定树高度 ⌈log₂(n+1)⌉，查找成功和失败最多都比较 ⌈log₂(n+1)⌉ 次；建堆时间 O(n)，堆排序时间 O(n log n) 且不稳定。链到折半查找实验、堆图解。
14. **比较排序的下界与稳定性**：基于比较的排序最坏情况下至少需要 ⌈log₂(n!)⌉ 次比较；十种内部排序的时间、空间、稳定性总表（可筛选）。验证：n ≤ 6 时画出决策树的高度。链到排序实验。

### 计算机组成原理（14 条）

1. **定点数的表示范围**：n 位（含符号位）补码 −2^(n−1) ~ 2^(n−1) − 1，原码和反码 −(2^(n−1) − 1) ~ 2^(n−1) − 1；补码 0 的表示唯一，比原码多表示一个最小负数。验证：拖动位数，数轴上标出三种编码的范围。
2. **溢出判断**：两个同号数相加结果符号相反即溢出；双符号位 01 为正溢出、10 为负溢出；最高位进位与次高位进位异或为 1 即溢出。验证：输入两个数和位数，三种判断方法同时给结论。
3. **IEEE 754 单精度**：值 = (−1)^S × 1.M × 2^(E−127)，阶码全 0 表示 0 或非规格化数，全 1 表示无穷或 NaN；规格化最大正数约 3.4 × 10^38，最小规格化正数 2^(−126)。链到 IEEE 754 实验。
4. **海明码校验位数**：k 个校验位、n 个数据位需满足 2^k ≥ n + k + 1；能纠正 1 位错，加总校验位可检测 2 位错。验证：拖动 n 看最小 k。链到海明码实验。
5. **存储器扩展**：用 a × b 位的芯片组成 A × B 位的存储器需要 (A/a) × (B/b) 片；位扩展、字扩展、字位同时扩展的地址线和片选线数量。验证：输入芯片和目标容量，画出芯片阵列。
6. **低位交叉编址**：m 体低位交叉存储器连续读取 m 个字的时间为 T + (m−1)r，其中 T 为存储周期、r 为总线传送周期，理想情况下 T = m r。
7. **Cache 地址划分**：主存地址 = 标记 + 组号（或行号）+ 块内地址；直接映射、全相联、k 路组相联下各字段位数；Cache 总容量还要算有效位、脏位、标记位。验证：输入主存容量、Cache 容量、块大小、相联度，画出地址字段。链到 Cache 写策略图解。
8. **Cache 命中率与平均访问时间**：命中率 h = Nc/(Nc + Nm)；同时访问时平均访问时间 Ta = h·Tc + (1−h)·Tm，先访问 Cache 再访问主存时 Ta = Tc + (1−h)·Tm；效率 e = Tc/Ta。两种口径都要给出并说明区别。
9. **CPU 性能**：CPU 时间 = 指令数 × CPI / 主频；MIPS = 主频 /(CPI × 10^6)；平均 CPI 按各类指令所占比例加权。
10. **Amdahl 定律**：整体加速比 S = 1 /((1 − f) + f/s)，f 为可改进部分所占比例，s 为该部分加速比；s 趋于无穷时上限 1/(1−f)。验证：拖动 f 和 s，画出加速比曲线。
11. **流水线性能**：k 段流水线执行 n 条指令时间 T = (k + n − 1)Δt；吞吐率 TP = n/T；加速比 S = nkΔt/T，n → ∞ 时趋于 k；效率 E = n/(k + n − 1)。验证：拖动 k 和 n，画时空图。
12. **扩展操作码**：指令字长固定时，每种地址码格式保留一部分编码作为扩展窗口；若某类指令有 x 条，剩余编码数 = 2^位数 − x，用于下一级扩展的编码数乘以 2^(新增位数)。验证：输入各类指令条数，判断能否编码。
13. **总线带宽**：总线带宽 = 总线宽度（字节）× 总线工作频率（每周期传送一次时）；突发传送下按“地址周期 + 若干数据周期”计算。
14. **I/O 方式的时间开销**：程序查询占 CPU 时间比例 = 每秒查询次数 × 每次查询时钟数 / 主频；中断方式按每次中断服务时钟数计算；DMA 方式只在每传送一个数据块时占用 CPU 做预处理和后处理。验证：同一设备三种方式的 CPU 占用率对比。

### 操作系统（14 条）

1. **死锁的资源下限**：n 个进程各需 k 个同类资源，系统资源数 m ≥ n(k − 1) + 1 时一定不会死锁；反过来已知 m 和 k，最多允许 ⌊(m − 1)/(k − 1)⌋ 个进程（k > 1）。验证：拖动 m，演示每个进程都拿 k − 1 个时的“最坏分配”。
2. **银行家算法的安全性**：Need = Max − Allocation；存在一个安全序列使每个进程都能依次满足 Need ≤ Work，系统就处于安全状态；安全状态一定不死锁，不安全状态不一定死锁。验证：输入矩阵，逐步找安全序列。
3. **信号量的含义**：S.value > 0 表示可用资源数；S.value < 0 时其绝对值表示等待队列中的进程数；互斥信号量初值 1，同步信号量初值一般为 0。链到生产者—消费者实验。
4. **调度指标**：周转时间 = 完成时间 − 到达时间；带权周转时间 = 周转时间 / 运行时间；等待时间 = 周转时间 − 运行时间；平均周转时间最短的非抢占调度是 SJF。验证：输入作业，FCFS、SJF、HRRN 的指标对比。
5. **有效访问时间**：无快表 EAT = 2t；有快表（命中率 a、快表访问时间 λ）EAT = a(λ + t) + (1 − a)(λ + 2t)，若快表与内存同时访问则改写；考虑缺页率 p 时 EAT = (1 − p) × 访存时间 + p × 缺页处理时间。
6. **多级页表级数**：逻辑地址 L 位、页大小 2^P 字节、页表项 E 字节，每页可放 2^P/E 个页表项，级数 = ⌈(L − P)/log₂(2^P/E)⌉。验证：输入参数，画出逻辑地址的分段。
7. **页表大小**：页表项个数 = 2^(逻辑地址位数 − 页内偏移位数)；页表大小 = 页表项个数 × 页表项字节数。
8. **Belady 异常**：FIFO 置换算法在分配的物理块增加时缺页次数可能反而增加；LRU 和 OPT 属于栈式算法，不会出现。验证：经典串 1,2,3,4,1,2,5,1,2,3,4,5 在 3 块时缺页 9 次、4 块时缺页 10 次。
9. **磁盘访问时间**：Ta = Ts + 1/(2r) + b/(rN)，Ts 为寻道时间、r 为转速、b 为读取字节数、N 为每道字节数。链到磁盘调度实验。
10. **混合索引的最大文件长度**：直接地址项 a 个、一级间接 b 个、二级间接 c 个，盘块大小 B、地址项 d 字节，每块可放 B/d 个地址，最大文件长度 = (a + b × (B/d) + c × (B/d)² + …) × B。验证：输入参数，画出索引结构。
11. **位示图换算**：盘块号 b = 字号 i × 字长 n + 位号 j（均从 0 开始）；反过来 i = b / n、j = b % n。从 1 开始编号的版本差 1，要单独说明。
12. **动态分区与碎片**：动态分区产生外部碎片，固定分区和分页产生内部碎片；分页的页内碎片平均为半页。链到动态分区实验。
13. **进程状态转换**：就绪 → 运行（被调度）、运行 → 就绪（时间片到或被抢占）、运行 → 阻塞（主动请求）、阻塞 → 就绪（事件发生，被动）；不存在阻塞 → 运行和就绪 → 阻塞。验证：点击任意两种状态，判断能否直接转换。
14. **程序并发的条件**：Bernstein 条件 R(P1) ∩ W(P2) = W(P1) ∩ R(P2) = W(P1) ∩ W(P2) = ∅ 时两段程序可以并发执行且结果确定。

### 计算机网络（14 条）

1. **奈奎斯特定理**：无噪声信道极限码元速率 2W 波特，极限数据传输速率 2W log₂V（V 为码元离散电平数）。验证：拖动 W 和 V。
2. **香农定理**：有噪声信道极限数据传输速率 C = W log₂(1 + S/N)，信噪比 dB = 10 log₁₀(S/N)；实际速率取奈奎斯特和香农两者中的较小值。验证：输入 dB 自动换算。
3. **时延与时延带宽积**：发送时延 = 数据长度 / 发送速率；传播时延 = 信道长度 / 传播速率；时延带宽积 = 传播时延 × 带宽，表示链路上能容纳的比特数。验证：动画显示链路上的比特。
4. **停等协议的信道利用率**：U = T_D /(T_D + RTT + T_A)；连续 ARQ 发送窗口为 W 时 U = min(1, W·T_D /(T_D + RTT))。链到滑动窗口实验。
5. **窗口上限**：n 位序号，GBN 发送窗口 W_T ≤ 2^n − 1，SR 发送窗口与接收窗口之和 ≤ 2^n，通常各取 2^(n−1)。验证：窗口超过上限时演示新旧帧混淆。
6. **CSMA/CD 最短帧长**：最短帧长 = 2τ × 数据传输速率，τ 为单程传播时延；10 Mb/s 以太网争用期 51.2 μs，最短帧 64 字节；截断二进制指数退避重传 k = min(重传次数, 10)，16 次失败丢弃。链到 CSMA/CD 实验。
7. **编码与速率**：曼彻斯特编码和差分曼彻斯特编码的码元速率是数据速率的 2 倍（每个比特中间都有跳变）。链到编码实验。
8. **子网划分**：主机号 h 位时可用主机数 2^h − 2；子网号 s 位可划分 2^s 个子网（CIDR 下全 0 全 1 子网可用）；广播地址为主机号全 1。验证：输入地址和前缀，算网络地址、广播地址、可用范围。
9. **路由聚合**：多个地址块取共同前缀；聚合后的前缀长度 = 共同前缀位数；最长前缀匹配。链到最长前缀匹配实验。
10. **IP 分片**：片偏移以 8 字节为单位，除最后一片外每片数据部分长度必须是 8 的整数倍；MF = 1 表示后面还有分片。链到 IP 分片实验。
11. **TCP 拥塞控制**：慢开始阶段 cwnd 每经过一个 RTT 翻倍；到达 ssthresh 后拥塞避免每 RTT 加 1；超时 ssthresh = cwnd/2、cwnd = 1；三个重复 ACK 时快重传、快恢复 cwnd = ssthresh（新的）。验证：拖动时间轴画 cwnd 曲线，可注入超时或三次重复确认。
12. **TCP 最大吞吐量**：吞吐量上限 = 窗口大小 / RTT；窗口受接收窗口、拥塞窗口共同限制，取较小值；窗口字段 16 位，最大 65535 字节，可用窗口扩大选项。
13. **TCP 序号与确认号**：确认号 = 期望收到的下一个字节的序号；SYN 和 FIN 各消耗一个序号，纯 ACK 不消耗。验证：一段三次握手和数据传输，逐个报文段算序号。
14. **以太网与交换**：以太网最短帧 64 字节、最长帧 1518 字节（数据部分 46 ~ 1500 字节）；集线器所有端口同一冲突域，交换机每个端口一个冲突域，路由器隔离广播域。链到交换机自学习图解。

## 四、每条性质的结构

每条性质是一张卡片，包含：

- **名称与章节**（如“二叉树叶子结点数 · 第 5 章 树与二叉树”）；
- **定义**：用到的概念，一两句话（如“度：结点拥有的子树个数”）；
- **结论**：一到三条公式或结论，公式用清晰的文字写法（下标、上标、取整符号都要正确显示）；
- **适用条件**：什么情况下成立，哪些条件改了就不成立（例如 n₀ = n₂ + 1 对任意非空二叉树成立，但 m 叉树要换成 n₀ = 1 + Σ(i−1)nᵢ）；
- **推导**：3 ~ 8 步，像过程图解一样可以上一步、下一步；
- **动手验证**：一个可交互的小动画，有参数输入或按钮，实时显示公式两边的计算结果和图形；
- **易错点**：2 ~ 3 条，例如“题目给的是高度还是深度”“从 0 开始还是从 1 开始编号”“τ 是单程还是往返”；
- **例题**：一道选择题，四个选项，点击选项立即判对错，显示解析；能确认年份的标“20xx 年真题”，不能确认的标“典型题”；
- **相关链接**：配套的动画实验和过程图解，点击直接跳到 `#lab-<id>` 或 `#proc-<id>`。

## 八、推导示例（写作口径）

### n₀ = n₂ + 1
第一步：设二叉树中度为 0、1、2 的结点数分别为 n₀、n₁、n₂，结点总数 n = n₀ + n₁ + n₂。第二步：除根结点外，每个结点都有一个分支指向它，所以分支数 B = n − 1。第三步：分支都是由度为 1 或 2 的结点发出的，度为 1 的发出 1 个，度为 2 的发出 2 个，所以 B = n₁ + 2n₂。第四步：联立得 n₀ + n₁ + n₂ − 1 = n₁ + 2n₂，化简得 n₀ = n₂ + 1。推广：度为 m 的树中 n₀ = 1 + n₂ + 2n₃ + … + (m−1)nₘ。

### 死锁资源下限
第一步：最坏情况是每个进程都已经拿到 k − 1 个资源，还差 1 个，谁也无法完成。第二步：这时一共用掉 n(k − 1) 个资源。第三步：只要再多 1 个资源，就能分给某一个进程让它完成并释放全部 k 个资源，其他进程依次完成。第四步：所以不发生死锁的最少资源数为 n(k − 1) + 1。易错点：题目问“可能发生死锁的最大资源数”时答案是 n(k − 1)。

### 流水线时间
第一步：第一条指令要经过全部 k 段，用时 kΔt。第二步：之后每过 Δt 流出一条指令，剩下 n − 1 条再用 (n − 1)Δt。第三步：总时间 T = (k + n − 1)Δt。第四步：吞吐率 TP = n/T，加速比 S = nkΔt/T，当 n 远大于 k 时 S 趋近于 k。易错点：各段时间不等时 Δt 取最长段的时间。

### 窗口上限
第一步：n 位序号可以表示 2^n 个序号。第二步：GBN 接收窗口为 1，若发送窗口等于 2^n，全部确认丢失时发送方重发的旧帧和接收方期待的新帧序号相同，接收方无法区分。第三步：所以 GBN 发送窗口最大 2^n − 1。第四步：SR 接收窗口大于 1，新旧窗口不能重叠，必须满足发送窗口 + 接收窗口 ≤ 2^n。

### CSMA/CD 最短帧长
第一步：站点发送后，最迟要经过 2τ 才能检测到碰撞。第二步：如果帧在 2τ 之内就发完了，站点就会以为发送成功，无法检测碰撞。第三步：所以帧的发送时间至少为 2τ，最短帧长 = 2τ × 数据传输速率。第四步：10 Mb/s 以太网取争用期 51.2 μs，得最短帧 512 位，即 64 字节。

### 多级页表级数
第一步：页大小 2^P 字节，页内偏移占 P 位，页号占 L − P 位。第二步：每个页表项 E 字节，一页可以放 2^P/E 个页表项，对应 log₂(2^P/E) 位页号。第三步：页号要分成若干段，每段不超过 log₂(2^P/E) 位。第四步：级数 = ⌈(L − P)/log₂(2^P/E)⌉。示例：32 位逻辑地址、4 KB 页、4 字节页表项，每页 1024 项、每段 10 位，(32 − 12)/10 = 2 级。

## 九、内容质量要求

- 术语和公式写法统一采用王道、唐朔飞、汤小丹、谢希仁教材；不同教材口径不同的地方（Cache 平均访问时间、完全二叉树高度的两种写法、位示图编号从 0 还是 1、快表与内存是否同时访问）必须写进“适用条件”或“易错点”。
