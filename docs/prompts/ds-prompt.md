# 408 实验室 · 数据结构动画实验与过程图解执行 Prompt

## 一、站长原话与现状

站长原话：

> 怎么数据结构的动画实验少这么多东西，还没有过程图解。

`/lab` 实验室目前的数据结构内容：

- 动画实验只有 3 个：排序动画（冒泡、直接插入、快速、堆、归并）、二叉树遍历（先序、中序、后序、层序）、Dijkstra 最短路径；
- 过程图解 0 个。组成原理、操作系统、计算机网络都已经有一整组图解，唯独数据结构空着。

数据结构在 408 里占 45 分，是四门课里分值最高的一门：选择题 1–11 共 11 道，外加一道 13 分左右的算法设计题（第 41 题）和一道 10 分左右的应用题（第 42 题）。应用题近十年几乎都考“手工模拟一个算法”：画出散列表并算 ASL、构造哈夫曼树算 WPL、画出 B 树插入后的样子、写出 Prim 或 Kruskal 的加边顺序、求拓扑序列和关键路径、写出 KMP 的 next 数组、写出某趟排序后的结果。选择题更是逐章覆盖：栈的出栈序列、循环队列判空判满、中缀转后缀、KMP、二叉树性质、线索二叉树、树与森林的转换、并查集、平衡二叉树旋转、红黑树、B 树与 B+ 树、图的遍历与生成树、最短路径、拓扑排序、关键路径、折半查找判定树、散列冲突处理、十种内部排序的过程与性质、外部排序的败者树和置换—选择排序。

现在站内这些考点几乎全部缺席，这就是站长说“少这么多东西”的原因。

## 二、深度剖析：站长真正要什么

1. **把数据结构补到和另外三门同样完整。** 站长看过组成原理、操作系统、计网的实验和图解，知道一个科目“完整”是什么样：几乎每个高频算法都有一个能自己改数据、一步一步看的实验，每个容易画错的结构变化都有一张能单步回退的图解。数据结构是分值最高的科目，反而最薄，这是不能接受的。
2. **数据结构的本质是“手工模拟”。** 第 42 题考的就是学生能不能在纸上把算法跑一遍。所以每个实验都要：①允许输入考试里那种规模的数据（8–15 个关键字、6–8 个顶点）；②每一步只做一件事并写清依据（“比较 23 与 19，23 > 19，进入右子树”）；③中间状态完整可见（表格、树形、数组、指针）；④最后给出考试要的答案（ASL、WPL、序列、next 数组、最小生成树权值）。
3. **区分“实验”和“图解”。** 实验是“算法 + 任意数据”：散列、KMP、哈夫曼、AVL、B 树、图算法、查找、排序。图解是“结构变化的固定过程”：链表插入删除时指针改的先后顺序、循环队列判满的三种方案、递归调用栈、线索化、树和森林与二叉树的转换、堆的上浮下沉、红黑树插入的几种情况、外部排序的败者树。图解的价值是把课本上一张静态图拆成十几步，让学生看清“先改哪根指针、为什么不能反过来”。
4. **把易错点做成“对比”。** 例如：线性探测与平方探测同一组数据的对比；Prim 与 Kruskal 加边顺序的对比；next 与 nextval 的对比；DFS 与 BFS 生成树的对比；AVL 四种旋转的对比；B 树与 B+ 树的对比；双链表插入时指针修改顺序“正确写法”与“错误写法”的对比。
5. **教材口径统一。** 以王道和严蔚敏《数据结构》为准：KMP 的 next 数组用下标从 1 开始、next[1] = 0 的写法（同时提示另一种从 0 开始的写法差 1）；B 树阶数 m、非根结点关键字个数 ⌈m/2⌉−1 到 m−1；平衡因子 = 左子树高 − 右子树高；散列表 ASL 失败时按“到第一个空位置的比较次数”计算，并注明各教材是否把与空位置的比较算一次。
6. **手机好用。** 站长主要在安卓手机上看，树和图在 390 宽的屏幕上要能看清：结点圆圈够大、可横向滑动；输入框能直接粘贴一串数字。

## 三、范围

### A. 动画实验（新增 14 个，加上原有 3 个，共 17 个）

**线性结构与串**
1. **中缀转后缀与后缀求值（栈）。** 输入中缀表达式（如 a+b*(c-d)-e/f 或 3+4*(2-1)-6/3），逐个扫描：操作数直接输出，左括号入栈，右括号弹栈到左括号，运算符按优先级弹出栈顶优先级不低于它的运算符再入栈；画出栈和输出序列。数值表达式再接着做后缀表达式求值（操作数栈）。统计栈的最大深度（选择题常考）。
2. **循环队列。** 容量 MaxSize 可调（默认 6），按钮“入队 x / 出队”，画出环形数组和 front、rear 指针；切换三种判满方案：牺牲一个单元（(rear+1)%MaxSize == front）、增设 size、增设 tag；实时显示队列长度公式 (rear − front + MaxSize) % MaxSize。
3. **KMP：next / nextval 与匹配过程。** 输入主串和模式串，先逐位求 next（显示每一位的最长相等前后缀），再求 nextval；然后逐步匹配：比较、失配后模式串按 next 右滑，主串指针不回溯；对比朴素匹配的比较次数。

**树与二叉树**
4. **哈夫曼树与哈夫曼编码。** 输入权值（如 7, 5, 2, 4 或带字符的 a:45 b:13 …），每一步从森林中选两棵权值最小的树合并，画出森林变化；最后给出每个字符的编码（左 0 右 1）和 WPL；说明哈夫曼树不唯一但 WPL 相同、结点总数 2n−1、没有度为 1 的结点。
5. **二叉排序树与平衡二叉树（AVL）。** 输入关键字序列逐个插入；BST 模式只插入并支持删除（叶子、只有一棵子树、两棵子树三种情况，用中序前驱或后继替代）；AVL 模式每次插入后计算平衡因子，找到最小不平衡子树，标明 LL / RR / LR / RL 并动画旋转。显示查找成功的 ASL。
6. **B 树插入与删除。** 阶数 m 可选 3 / 4 / 5，逐个插入关键字：找到终端结点插入，关键字数超过 m−1 时从中间位置 ⌈m/2⌉ 分裂，中间关键字上移，可能一路分裂到根使树长高；删除支持“直接删除”“向兄弟借”“与兄弟合并”三种情况。同时显示每个结点关键字数的上下限。
7. **并查集。** 输入一串 Union / Find 操作，画出森林和 parent 数组；可选“普通合并”“按秩（高度）合并”“路径压缩”，对比树的高度。

**图**
8. **图的遍历 DFS / BFS。** 默认 8 个顶点的无向图（可编辑边表），按邻接表中的顺序访问，画出访问序列、栈或队列、visited 数组，以及对应的深度优先生成树和广度优先生成树；可切换有向图。
9. **最小生成树 Prim / Kruskal。** 带权无向图（6–7 个顶点），Prim 从指定顶点出发，每一步显示 lowcost 数组、选中的最小边；Kruskal 按权值排序所有边，逐条判断是否构成回路（用并查集），显示加边顺序；最后两者权值和相同。
10. **拓扑排序与关键路径。** AOV 网：显示入度数组和栈 / 队列，逐个输出入度为 0 的顶点；AOE 网：依次求事件最早发生时间 ve、最迟发生时间 vl、活动最早开始 e、最迟开始 l、时间余量 l − e，标出关键活动和关键路径。
11. **Floyd 最短路径。** 4–5 个顶点，逐轮以 k 为中间顶点更新距离矩阵 A 和路径矩阵 path，变化的格子高亮，显示更新依据 A[i][k] + A[k][j] < A[i][j]。

**查找与排序**
12. **散列表。** 输入关键字、表长、散列函数 H(key) = key % p，冲突处理可选线性探测、平方探测（±1², ±2², …）、拉链法；逐个插入并显示每个关键字的探测序列和比较次数；最后计算查找成功和查找失败的平均查找长度，并列出算式。
13. **折半查找与判定树。** 输入有序表和要查的关键字，显示 low / mid / high 指针移动；同时画出该表的折半查找判定树（mid 向下取整），标出查找路径，计算 ASL 成功与 ASL 失败。
14. **排序补充：希尔、简单选择、折半插入、基数排序。** 希尔排序可设增量序列（默认 n/2 逐次减半），每一趟显示各组；简单选择显示每趟选出的最小值；基数排序（LSD）显示每一趟按个位、十位、百位分配到 10 个队列再收集；每一趟结束给出“第 i 趟后的序列”（这正是选择题的问法），并在考点中列出稳定性和时间复杂度。

### B. 过程图解（新增“数据结构”一组，8 个）

1. **单链表与双链表的插入删除。** 模式：单链表头插、按位序插入、删除；双链表插入、删除。每一步只改一根指针，画出改之前和改之后，并演示“错误顺序”（双链表插入时先改 p->next 导致后继丢失）。
2. **循环队列的队空与队满。** 三种方案并列：牺牲一个单元、增设 size、增设 tag；按“入队到满 → 出队 → 再入队绕回”的顺序走，标出 front、rear 的位置与判断条件。
3. **递归与函数调用栈。** 以 Fib(4) 或阶乘 fact(4) 为例：每次调用压入一个栈帧（参数、返回地址、局部变量），递归到底后逐层返回，并画出递归调用树；说明递归深度与栈空间。
4. **二叉树的中序线索化。** 一棵 6–7 个结点的二叉树，按中序遍历顺序访问，pre 指针跟随：左孩子为空则 lchild 指向前驱、ltag = 1；pre 的右孩子为空则 rchild 指向当前结点、rtag = 1；最后处理最后一个结点。显示 ltag、rtag 表。
5. **树、森林与二叉树的转换。** 树转二叉树（左孩子右兄弟：加线、抹线、旋转），森林转二叉树（各树转换后用右指针相连），并给出遍历对应关系：树的先根 = 二叉树先序，树的后根 = 二叉树中序。
6. **堆的插入与删除。** 小根堆：建堆（从 ⌊n/2⌋ 开始向下筛选），插入到末尾后上浮，删除堆顶时用末尾元素替换后下沉；同时画出数组和完全二叉树，统计比较次数。
7. **红黑树的插入。** 新结点为红色；父结点为黑直接结束；父红叔红：父、叔变黑，爷变红，爷作为新结点继续向上；父红叔黑：按 LL / RR / LR / RL 旋转并变色。插入一组关键字（如 20, 10, 5, 30, 40, 57, 3, 2）展示各种情况，并标出黑高。
8. **外部排序：败者树与置换—选择排序。** 模式一：置换—选择排序生成初始归并段（工作区 WA 大小 3）；模式二：k 路归并的败者树（k = 5），叶子为各归并段的当前记录，内部结点记录败者，根上方记录冠军，每输出一个记录后从该叶子向上重新比较；模式三：最佳归并树（哈夫曼思想，补虚段 (k−1) − (n−1) % (k−1) 个）。

## 六、验收标准

1. 中缀 a+b*(c-d)-e/f → 后缀 abcd-*+ef/-；3+4*(2-1)-6/3 → 值 5。
2. KMP：模式串 abaabc 的 next = 0 1 1 2 2 3，nextval = 0 1 0 2 1 3（下标从 1 开始）。

5. B 树：任何插入序列后，非根结点关键字个数在 ⌈m/2⌉−1 到 m−1 之间，所有叶结点在同一层。
6. 散列：关键字 {19, 14, 23, 1, 68, 20, 84, 27, 55, 11, 10, 79}、H = key % 13、表长 16、线性探测 → ASL 成功 = 30/12 = 2.5。

9. Floyd 结果与对每个顶点各跑一次 Dijkstra 的结果一致（无负权）。
10. 排序补充：任意输入最终有序；希尔排序每一趟后的序列与按增量分组直接插入的结果一致；基数排序每一趟按对应位稳定分配收集。

## 七、逐步脚本（实现时每一步的文字依据）

### 中缀转后缀
以 a+b*(c-d)-e/f 为例：扫描 a，操作数直接输出，输出 a；扫描 +，栈空，入栈；扫描 b，输出；扫描 *，栈顶 + 优先级低于 *，不弹，* 入栈；扫描 (，直接入栈；扫描 c，输出；扫描 -，栈顶是 (，不弹，- 入栈；扫描 d，输出；扫描 )，依次弹出 - 直到遇到 (，( 出栈丢弃；扫描 -，栈顶 * 优先级高于 -，弹出 *，栈顶 + 与 - 同级，也弹出（左结合），然后 - 入栈；扫描 e，输出；扫描 /，栈顶 - 优先级低，/ 入栈；扫描 f，输出；扫描结束，依次弹出 / 和 -。输出 abcd-*+ef/-，栈的最大深度为 4（含左括号；只计运算符为 3）。

### KMP 的 next 数组
模式串 a b a a b c：next[1] = 0（约定），next[2] = 1（约定）；第 3 位前面的子串 ab 最长相等前后缀长度 0，next[3] = 1；第 4 位前面 aba 最长相等前后缀 a，长度 1，next[4] = 2；第 5 位前面 abaa 最长相等前后缀 a，next[5] = 2；第 6 位前面 abaab 最长相等前后缀 ab，next[6] = 3。nextval：若 P[j] 等于 P[next[j]]，则 nextval[j] = nextval[next[j]]，否则等于 next[j]；于是 nextval = 0 1 0 2 1 3。

### 哈夫曼树
权值 7, 5, 2, 4：第一步选最小的 2 和 4 合并成 6；第二步森林为 7, 5, 6，选 5 和 6 合并成 11；第三步 7 与 11 合并成 18 作为根。叶子 7 的路径长度 1，5 为 2，2 和 4 为 3，WPL = 7×1 + 5×2 + 2×3 + 4×3 = 35。

### 平衡二叉树
插入 3、2、1：插入 1 后结点 3 的平衡因子变成 2，最小不平衡子树以 3 为根，插入位置在其左孩子的左子树上，属于 LL 型，以 2 为轴右旋，2 成为根，3 成为 2 的右孩子。LR 型则先对左孩子左旋再对根右旋，RL 型对称。

### B 树插入（3 阶）
3 阶 B 树每个结点最多 2 个关键字。依次插入 10、20、30：插入 30 后结点有 10、20、30 三个关键字，超过上限，从中间位置分裂：20 上移成为新根，10 和 30 各成一个结点，树高加 1。继续插入时，总是先找到终端结点再插入，溢出时分裂，中间关键字插入父结点，父结点溢出则继续分裂。

### 散列表（线性探测）
H(19) = 6，放入 6；H(14) = 1，放入 1；H(23) = 10；H(1) = 1 冲突，探测 2，放入 2，比较 2 次；H(68) = 3；H(20) = 7；H(84) = 6 冲突，探测 7 仍冲突，探测 8，放入 8，比较 3 次；依次类推，所有关键字的比较次数之和为 30，ASL 成功 = 30/12 = 2.5。查找失败时，对散列地址 0 到 12 中的每一个，从该位置起向后比较直到遇到空位置，平均后得到 ASL 失败。

### 折半查找
有序表 11 个元素，下标 1–11：第一次 mid = 6；查找值较小则 high = mid − 1 = 5，mid = 3；以此类推。判定树第 1 层 1 个结点，第 2 层 2 个，第 3 层 4 个，第 4 层 4 个，ASL 成功 = (1×1 + 2×2 + 3×4 + 4×4)/11 = 33/11 = 3。

### Prim 与 Kruskal
Prim 从顶点 1 出发，lowcost 记录每个未加入顶点到当前生成树的最小边权；每一步选 lowcost 最小的顶点加入并更新 lowcost，适合稠密图，时间复杂度 O(|V|²)。Kruskal 把所有边按权值排序，依次检查每条边的两端是否已在同一连通分量中（用并查集 Find），不在则加入并 Union，在则跳过，适合稀疏图，时间复杂度 O(|E|log|E|)。

### 关键路径
先按拓扑序求 ve：ve(源点) = 0，ve(k) = max{ve(j) + 活动 <j,k> 的持续时间}；再按逆拓扑序求 vl：vl(汇点) = ve(汇点)，vl(j) = min{vl(k) − 活动 <j,k> 的持续时间}；活动 <j,k> 的 e = ve(j)，l = vl(k) − 持续时间；l − e = 0 的活动是关键活动，关键活动组成关键路径。考点：缩短关键活动不一定能缩短工期，因为关键路径可能不止一条，而且缩短到一定程度后会变成非关键活动。

### 双链表插入
在 p 之后插入 s：第一步 s->next = p->next；第二步 p->next->prior = s；第三步 s->prior = p；第四步 p->next = s。第一、二步必须在第四步之前，否则 p 原来的后继就找不到了。错误顺序模式中先执行 p->next = s，接着 s->next = p->next 让 s 指向自己，画出链断开。

### 红黑树插入
插入 20 作为根，染黑；插入 10，父为黑，结束；插入 5，父 10 为红、叔 30 不存在（视为黑），是 LL 型，以 10 为轴右旋，10 染黑、20 染红；插入 30，父 20 红、叔 5 红，父叔染黑，爷 10 染红，爷是根再染黑；之后的插入依次覆盖其余情况。每一步显示结点颜色、黑高，并检查“根黑、红结点的孩子都是黑、每条路径黑结点数相同”。

### 败者树
5 路归并，叶子 b0–b4 为各归并段的当前首记录；从叶子向上两两比较，内部结点记录败者（较大者），胜者继续向上，最终冠军（最小者）放在 ls[0]；输出冠军后，用该归并段的下一个记录替换对应叶子，只需沿这片叶子到根的路径重新比较 ⌈log₂k⌉ 次。考点：败者树使比较次数与 k 无关，所以可以增大 k 减少归并趟数；置换—选择排序得到的初始归并段长度不等，平均约为工作区大小的两倍。

### 循环队列与并查集
循环队列（MaxSize = 6，牺牲一个单元）：初始 front = rear = 0，队空；依次入队 5 个元素后 rear = 5，(5 + 1) % 6 == 0 == front，队满，此时只存了 5 个元素；出队两次 front = 2，再入队两次 rear 绕回到 1；队列长度 (1 − 2 + 6) % 6 = 5。并查集：初始每个元素的 parent 为 −1（根结点存集合大小的相反数）；Union(1, 2) 让 2 的根指向 1 的根；Find(x) 沿 parent 向上找根；按秩合并时让小树并入大树，树高不超过 ⌊log₂n⌋ + 1；路径压缩在 Find 时把路径上所有结点直接挂到根下，使后续查找接近常数时间。

### 堆与置换—选择排序
小根堆插入：新元素放在数组末尾，与父结点 ⌊i/2⌋ 比较，比父结点小就交换，一路上浮直到不小于父结点或到达根；删除堆顶：把末尾元素移到堆顶，与较小的孩子比较，大于孩子就交换，一路下沉。建堆时从最后一个非叶结点 ⌊n/2⌋ 开始依次向前做下沉，建堆的时间复杂度为 O(n)。置换—选择排序：先把工作区装满，选出最小的记录输出并记为 MINIMAX，再从输入读入一个记录；之后每次在工作区中选出比 MINIMAX 大的最小记录输出，若都比 MINIMAX 小，当前归并段结束，开始下一个归并段。
