数据结构

45 分 · 7 章 · 选择题 1–11 + 2 道综合题

点选章节，右侧看核心考点和最常丢分的一处。

第 7 章考频 ★★★

排序

核心考点

  • 插入类：直接插入、折半插入、希尔
  • 交换类：冒泡、快速；选择类：简单选择、堆排序
  • 归并排序、基数排序
  • 外部排序：败者树减少比较次数
  • 置换-选择排序生成更长的初始归并段
  • 最佳归并树：k 叉哈夫曼树，必要时补虚段
!易错

每趟能确定一个元素最终位置的是冒泡、简单选择、快排、堆排序；直接插入和希尔不能。折半插入只减少比较次数，移动次数不变，仍是 O(n²)。

计算机组成原理

45 分 · 6 章 · 选择题 12–22 + 2 道综合题

计算量最大的一门，存储器层次结构和 CPU 是重点。

第 6 章考频 ★★★

总线和输入/输出系统

核心考点

  • 总线带宽 = 总线宽度 × 总线频率 ÷ 每次传送的时钟周期数
  • 总线事务与定时：同步定时 vs 异步定时（不互锁、半互锁、全互锁）
  • I/O 接口：数据、状态、控制端口；端口统一编址 vs 独立编址
  • 程序查询方式
  • 中断响应过程、中断屏蔽字、多重中断
  • DMA：停止 CPU、周期挪用、交替访存
  • I/O 时间占 CPU 时间比例的计算
!易错

一个时钟周期传两次（如 DDR）时带宽要乘 2，宽度单位是位、换算成字节要除以 8；中断响应优先级由硬件排队决定，处理优先级由屏蔽字决定，二者可以不同；DMA 只在整块传完时请求一次中断。

操作系统

35 分 · 5 章 · 选择题 23–32 + 2 道综合题

PV 操作和内存管理是综合题常客。

第 1 章考频 ★★★

操作系统基础

核心考点

  • 特征：并发、共享、虚拟、异步；四大管理功能
  • 内核态/用户态与特权指令
  • 中断（外部）与异常（内部：故障、陷阱、终止）
  • 系统调用：陷入指令进入内核
  • 结构：分层、模块化、宏内核、微内核；操作系统引导
  • 虚拟机：第一类（裸机）与第二类（寄宿）
!易错

陷入（访管）指令在用户态执行，执行后才进入内核态；关中断、置时钟等特权指令只能在内核态执行。

计算机网络

25 分 · 6 章 · 选择题 33–40 + 1 道综合题

网络层与传输层分值最重。

第 1 章考频 ★★★

计算机网络概述

核心考点

  • OSI 七层、TCP/IP 四层、教学用五层
  • 发送、传播、排队、处理四种时延
  • 时延带宽积 = 传播时延 × 带宽
  • 往返时延 RTT
!易错

发送时延 = 数据长度 ÷ 带宽，与距离无关；传播时延 = 距离 ÷ 传播速率，与带宽无关。

入队 rear = (rear + 1) % MaxSize，出队 front = (front + 1) % MaxSize。只靠 front == rear 无法区分空和满，三种办法：①牺牲一个单元，队满 (rear + 1) % MaxSize == front，最多存 MaxSize − 1 个；②增设 size，队空 size == 0、队满 size == MaxSize；③增设 tag，入队置 1、出队置 0，front == rear 时 tag 为 0 是空、为 1 是满。队列长度 (rear − front + MaxSize) % MaxSize。注意题目约定：有的教材让 rear 指向队尾元素本身，此时公式整体差 1。

next[j] = P[1..j−1] 的最长相等前后缀长度 + 1，约定 next[1] = 0、next[2] = 1（下标从 1 开始，国内考题最常见的约定；若下标从 0 开始，next 整体减 1，首位为 −1）。失配时主串指针 i 不回溯，模式串指针 j = next[j]；j = 0 时 i、j 同时后移。nextval：若 P[j] = P[next[j]] 则 nextval[j] = nextval[next[j]]，否则等于 next[j]。KMP 时间复杂度 O(m + n)，朴素匹配最坏 O(mn)；主串与模式串部分匹配多时 KMP 优势才明显。

考点

每次从森林中选两棵根权值最小的树合并，新根权值为两者之和；n 个叶子合并 n − 1 次，结点总数 2n − 1，没有度为 1 的结点。WPL = Σ 叶子权值 × 路径长度 = 所有非叶结点权值之和。权值相同时选法不同、左右次序不同，哈夫曼树不唯一，但 WPL 相同且最小。哈夫曼编码是前缀编码（任何编码都不是另一个的前缀），左 0 右 1 只是约定。

叶子 n 8森林中树的棵数 8已合并 0 / 7

初始森林：8 棵只有根结点的树，权值 5、29、7、8、14、23、3、11。每一步选两棵根权值最小的树合并。

本实验的取法：权值相同时先取在森林中排得靠前的（新结点排在最后），较小者作左孩子。换一种取法树形会变，但 WPL 不变。平均码长 = WPL / 权值总和。

考点

二叉排序树中序遍历有序；插入的新结点一定是叶结点。删除：叶结点直接删；只有一棵子树就让子树顶替；有两棵子树用中序直接后继（或前驱）替代再删它。AVL 平衡因子 = 左子树高 − 右子树高，|BF| ≤ 1。插入后只需调整离插入点最近的最小不平衡子树：LL 右旋、RR 左旋、LR 先左后右、RL 先右后左，一次调整后整棵树恢复平衡。高度为 h 的 AVL 最少结点数 n(h) = n(h−1) + n(h−2) + 1（1, 2, 4, 7, 12…），查找 O(log n)。

左右滑动查看
考点

m 阶 B 树：每个结点至多 m 棵子树、m − 1 个关键字；非根结点至少 ⌈m/2⌉ 棵子树、⌈m/2⌉ − 1 个关键字；根至少 1 个关键字；所有叶结点（终端结点）在同一层。插入总在终端结点，溢出时从第 ⌈m/2⌉ 个关键字处分裂、中间关键字上移，分裂到根时树长高。删除非终端结点的关键字先用前驱（或后继）替代；下溢时兄弟够借就“父下移、兄上移”，不够借就与兄弟及父结点的分隔关键字合并，合并可能一路传到根使树变矮。含 n 个关键字的 m 阶 B 树高度 h ≤ log⌈m/2⌉((n+1)/2) + 1。

左右滑动查看
考点

并查集用双亲表示法：parent[x] 是 x 的双亲，根结点的 parent 为负数（其绝对值是集合大小）。Find 沿 parent 走到根，Union 先 Find 两个根再把一个根挂到另一个下。普通合并可能退化成链，Find 最坏 O(n)；按秩（高度）或按大小合并后树高 ≤ ⌊log₂n⌋ + 1，Find 为 O(log n)；再加路径压缩，均摊接近 O(α(n))，几乎是常数。Kruskal 算法用并查集判断加边是否成环。

DFS 一条路走到底再回头，靠递归（或显式栈）记住回退点，访问次序像树的先序；BFS 一圈一圈向外扩，靠队列，顶点入队时就打上 visited 标记，避免同一顶点进队两次。时间：邻接矩阵要扫整行，O(|V|²)；邻接表每条边看常数次，O(|V|+|E|)。同一个图的邻接矩阵只有一种，邻接表里邻接点的先后却可以不同，所以用邻接表时遍历序列和生成树都随邻接点次序变化——切换上方“按边表顺序”看看序列怎么变（默认按编号从小到大）。无向图不连通时，一次遍历只走完一个连通分量，外层要调用的次数就是连通分量个数。

结论二：树的后根 = 二叉树的中序

结点 x 在二叉树中的左子树就是它原来的全部子孙，中序先访问左子树再访问 x，正是“先子树后根”。

考点：森林的中序遍历（也有资料叫“后序遍历”，即依次对每棵树做后根遍历）= 对应二叉树的中序遍历。树没有“中根遍历”。

考点
  • 树转二叉树：兄弟加线 → 只留与第一个孩子的连线 → 旋转 45°；左指针 = 第一个孩子，右指针 = 右兄弟。
  • 树转换得到的二叉树，根结点没有右子树；森林转换得到的二叉树，根的右链上是其余各树的根。
  • 树的先根遍历 = 二叉树先序；树的后根遍历 = 二叉树中序。
  • 森林的先序 = 二叉树先序；森林的中序（各树依次后根）= 二叉树中序。

扩展操作码的编码条件

定义扩展操作码：指令字长固定，地址码少的指令把多出的地址字段让给操作码，操作码长度随地址数减少而增加。短操作码中留出的若干编码作为“扩展窗口”，充当更长操作码的前缀。

结论
  • 某级操作码 m 位、该类指令 x 条：剩余 2ᵐ − x 个编码作为扩展窗口
  • 下一级可用编码数 = (2ᵐ − x) × 2ᵈ，d 为新增的操作码位数（让出的地址字段位数）
  • 逐级扣除，每一级指令数都不超过该级可用编码数才能编码；短操作码不能是长操作码的前缀

适用条件操作码按前缀码设计（短码不是长码的前缀），各类指令按地址数从多到少排列；指令字长固定、各地址字段等长。若题目说“操作码定长”则不能扩展，所有指令共用 ⌈log₂(总条数)⌉ 位操作码。

推导
1 / 5
  1. 地址最多的一类（例如三地址）留给操作码 m = 字长 − 3A 位，共 2ᵐ 个编码。
  2. 该类 x 条指令各占一个编码，剩下 2ᵐ − x 个作为扩展窗口，不能再单独作为指令。
  3. 下一类（二地址）把一个 A 位地址字段并入操作码，每个窗口后面接 A 位，得到 (2ᵐ − x) × 2ᴬ 个编码。
  4. 依此类推：每一级可用编码 = 上一级剩下的窗口数 × 2ᵈ。
  5. 最后一级的指令数不超过可用编码数就能编码；求最短字长就从小到大试，直到每一级都放得下。
易错点
  • 剩余窗口要乘 2ᵈ 而不是加 2ᵈ，而且要先减去本级已经用掉的编码。
  • 求“至少多少位”时，若指令要按字节存放，算出的位数还要向上取到 8 的倍数。
  • “最多还能有多少条一地址指令”是在其他各级占用之后剩下的量，各级此消彼长。

    • 数据结构队列↔网络路由器输出队列

    • 数据结构循环队列↔操作系统生产者-消费者

    • 操作系统生产者-消费者↔操作系统缓冲区

      缓冲区是同步问题的载体

    • 组成指令流水线↔操作系统进程同步
